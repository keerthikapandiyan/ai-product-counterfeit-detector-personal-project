# AI Product Counterfeit Detector

An AI-based application that analyzes product images to identify whether a product is potentially **Genuine or Counterfeit**.

## Features

- Upload a product image
- Analyze the uploaded image using AI
- Classify the product as Genuine or Counterfeit
- Simple and user-friendly Streamlit interface

## Technologies Used

- Python
- Machine Learning / Deep Learning
- Computer Vision
- OpenCV
- Streamlit
- NumPy
- Pandas
